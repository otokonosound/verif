# Politique de confidentialité — VÉRIF (prototype)

VÉRIF est conçu selon le principe de minimisation des données.

## Prototype actuel
- Le moteur local analyse le texte dans le navigateur lorsqu'il est utilisé en fallback.
- L'OCR des images est exécuté côté client avec Tesseract.js.
- L'historique affiché dans l'interface est conservé en mémoire de session et n'est pas un compte utilisateur.
- Le serveur d'analyse ne doit pas journaliser le contenu des messages ni les données personnelles.

## Avant commercialisation
La version publique devra compléter cette politique avec l'identité de l'éditeur, les finalités précises, les bases légales, les durées de conservation, les sous-traitants, les droits des personnes et les coordonnées de contact, conformément au RGPD applicable.

Ce document est un document technique de préparation et ne constitue pas un avis juridique.
